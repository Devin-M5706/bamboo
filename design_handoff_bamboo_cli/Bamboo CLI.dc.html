bamboo · terminal ui mockups

Four states, lapdog's banner grammar, bamboo's colors

Same compact shape as lapdog: oversized block wordmark on the left, version and a short blurb stacked tight on the right, everything flush to the prompt. Orange #e8783f carries the wordmark and headings; a mint #4fc3a1 secondary carries anything that means "good, verified, safe" — matches, ledger hits, the dry-run promise. Hero sits in window chrome; the rest run bare so they read as one continuous session.
